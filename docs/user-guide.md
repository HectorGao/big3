# 举个铁子 · 使用指南

[项目首页](../README.md) · [文档导航](README.md)

下文以网页端为主。微信共用计算逻辑，但账号和部分新版交互尚未接入。界面能显示的功能不代表当前访问的站点已部署后端。

## 建立档案

在“我的档案”填写年龄、体重、训练经验、目标、可训练日与最小加重档位。三大项填写实际完成的重量、次数和日期；多次成绩会显示 e1RM 估算，不应标成实测极限。

杠铃使用总重，双哑铃通常使用单只重量，器械使用标重。相同数字不代表相同负荷；更换器械后需确认标识，不能直接套用另一台设备的能力。档案 PB 不用于推算所有辅助动作。

## 查看与调整计划

1. 在“今日训练”选择查看日期、深蹲 / 卧推 / 硬拉及训练日类型。
2. 填写当天疲劳及相关肌群酸痛、疼痛情况。图中涉及组数是自然数，颜色只是负荷提示，不是生理恢复率。
3. 核对用户选择与系统实际采用的类型。高疲劳、疼痛或恢复不足可能导致减量或拒绝负重建议；页面应说明原因。
4. 按可用器械筛选、替换或增加动作。动作的选择理由、组次理由和重量来源可供核对；器械替代不等于三大项专项训练完全等效。
5. 卡片可收起，保留重量、组次、单位和图解摘要；使用排序手柄调整顺序，按需收藏方案。

未来计划只作建议，不会提前算作训练完成。执行时以用户确认的实际日期重新评估，不能把未来日期保存为已经发生的训练。

## 完成训练

开始后冻结目标处方，实际重量、次数与余力另外保存。可以“查看训练计划”，再“继续当前训练”，无需放弃草稿。冻结目标不会因为后来改了档案或查看其他日期而改写。

- **待试重**：没有可靠同动作记录时，先轻负荷确认可控重量、次数和余力；合适后填入工作组。不要为了消除待定状态而随意填零。
- **直接填写**：可跳过试重流程，自行记录重量与次数；这不表示软件已验证该负荷安全合理。
- **完成 / 放弃**：每组记录实际结果，不做的组可放弃或保持未完成；结束时只统计实际完成组。试重不是正式工作组或 PB，但可参与恢复评估。
- **图解与单位**：训练中可查看动作阶段；动态动作按次数，静态保持按秒，不把核心保持时间当成重复次数。
- **结束与保存**：保存后按照实际项目、负荷及反馈重算未来两周。历史删除仍需逐次确认；不要将删除当作修正未完成建议的方式。

主项感觉强度可参考：6 约还能做 4 次，7 约 3 次，8 约 2 次，9 约 1 次，10 无法再做一次。这是主观近似，不要求为了记录而做到力竭。明显不适时停止负重，软件不能代替专业评估。

## 收藏与补录

可收藏自己调整过的动作组合与顺序，后续载入同类训练，再修改重量、次数或动作。收藏是参考方案，不会自动证明当日恢复允许，也不锁定能力永远不变。

忘记记录时选择已发生的日期，进入补录并载入收藏或相应计划。补录只填写实际发生的组，不需要模拟组间休息；保存后纳入实际统计。未知反馈保持未知，不补造历史余力、疼痛或精确时间。

## 账号、回声与备份

- 使用已运行后端的站点才可注册登录、同步和发布“训练回声”。无后端的静态站点只能保存在本机，登录报服务不可用不是账号密码错误的证明。
- 用户名为 3–24 位字母、数字或下划线，密码 8–128 位，没有公开通用密码。访客档案需主动确认导入，不会自动上传。
- 训练回声位于页面底部，可进入详情发布文字与表情。未隐藏回声会公开展示，不要发布个人训练隐私或联系方式；管理员可隐藏、显示并调整全站样式。
- 登录账号修改后应确认同步成功再离开；多设备冲突不会静默覆盖，先保留副本再选择。退出账号不一定清除本机缓存，共享设备请使用独立浏览器会话。
- 换域名或设备前在档案页导出备份。管理员可手动下载真实用户的周备份，见 [备份说明](production-accounts-backup.md)；不是自动定时下载，也不含完整服务器数据库。
- 研究授权为独立选择；备份或使用软件不等于同意模型训练。授权数据准备见 [研究说明](local-model-preparation.md)。
