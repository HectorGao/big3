# 举个铁子 v0.2.5

构建号：20260922.3。仅更新本地版本，未发布到线上。

## 修复

- 主项最近实际组缺少余力、目标次数改变时，不再遮蔽有效的同主项 PB。使用同项 PB/e1RM 的保守基准，并明确显示来源和热身确认要求。
- 较旧历史估算不再覆盖日期更新的档案 PB。近期失败、动作失控、疲劳、疼痛及过期能力记录限制继续生效。
- 没有可靠来源的辅助动作/不同变式/不同器械仍待试重，不从三大项换算；既有历史及已开始的草稿不改写。

- 授权研究导出 schema 2，记录实际/目标组、当前授权名单、稳定去标识 ID、来源版本；过滤测试及模拟数据。
- 新训练冻结当时的档案和计算版本，旧训练不倒填。
- 新增 `research:prepare`，管理备份不能直接作为研究输入。输出样本、排除原因、按时间及用户划分的评估集，以及两个非学习基线的误差报告。
- 未训练模型，不直接接入处方。详见 [本地研究准备](local-model-preparation.md)。
