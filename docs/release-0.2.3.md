# 举个铁子 v0.2.3 / 20260922.1

## 布局与材质

- 训练回声作为正常文档流中的底部区域，位于正文之后、版本页脚之前。五个导航页面共用该结构，不在顶部轮播，也不固定悬浮遮住训练控件。顶部只保留打开回声详情的按钮。
- 回声卡片与控制按钮使用通透填充、背景模糊、饱和度、内外边缘高光及轻阴影；鼠标移动改变卡片高光角度，不移动点击目标。触摸设备不运行跟随反光。
- 正文覆盖层由 88% 不透明度降低到 20%；留言背景由页面中部起始改为贯穿页面。表单输入、数值、主要训练卡片保持较实的底色，兼顾读取和背景可见性；不将工作界面做成整页强模糊。
- 桌面与手机控制按钮至少 44 px。手机纵向回声改成单列交错显示两条消息流，不隐藏其中一半消息；底部导航不遮住回声和页脚操作。
- 管理员面板改称“底部回声”。原 API 字段 `topStyle`、`topSpeed` 保留以兼容已保存的设置；不迁移、不重写用户配置。速度、方向、隐藏内容、个人风格、暂停等继续生效。

视觉参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 对透明材质、控制层和内容层的区分。本次为 CSS 实现的网页近似效果，不使用或声称实现 Apple 原生 Liquid Glass 渲染，也不对训练内容进行物理折射变形。

## 验证与边界

- `npm test`：170 项共享、账户 API、存储及模拟原生测试通过，训练算法未更改。
- `test:echo-glass-browser`：1280、768、390、360 px；五页的底部顺序、四种回声风格、可读正文、无横向溢出、44 px 触点、打开回声详情、档案不变。通过开关背景后的截图像素差异确认背景实际可见，通过鼠标移动前后截图确认高光实际改变。
- `test:echo-settings-browser`：管理员预览、保存、其他页面刷新、速度与颜色、并发冲突、隐藏留言过滤和权限回归通过。
- `test:compact-browser`：训练卡片折叠与排序、冻结数据、完整表情选择、无误提交以及玻璃强度对照回归通过。
- 减少动态效果时停用动画和跟随高光；减少透明度或增强对比度时回退为实色并隐藏装饰背景；不支持 backdrop-filter 时保留实色可读卡片。

浏览器测试使用临时数据库及独立测试存储，不修改真实账号。效果已在桌面 Chrome 与手机视口查看；Safari/iOS 真机、微信开发者工具及微信真机未验证。本轮只调整网页 UI，不同步原生小程序玻璃样式，不推送或正式发布。
