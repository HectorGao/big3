# 本地训练算法研究准备

本轮交付是数据入口、样本质检、评估基线及未来模型接口准备。没有训练深度学习模型，没有用真实用户记录做实验，没有把模型接入在线处方。四个 demo 的三个月记录仅用于软件测试，不是运动科学证据。

## 每周流程

1. 管理员登录，在“用户管理”下载每周档案备份。该文件只作运维恢复，不能直接拿去训练。
2. 同一页面选择“导出授权研究数据”。仅包含当前明确同意的真实用户，自动排除 demo、标记为模拟的档案和训练。不含用户名、密码、留言、器械备注或自由文本。
3. 将研究快照保存在私密目录，运行下面的本地准备命令。每周选择一个新的输出目录；不合并历次快照，不覆盖已有结果。

```sh
npm run research:prepare -- ~/Downloads/big3-consented-research-时间戳.json runtime/research/2026-09-22
```

输入使用实际下载的文件名。输出目录下有：

- `manifest.json`：来源文件校验值、快照标识、样本任务、特征清单。
- `dataset.json`：训练/验证/时间测试/新用户测试的逐组样本。
- `report.json`：可用人数、组数、排除原因、缺失信息边界、基线误差和是否可以考虑离线实验。

文件权限为仅当前用户读写；目录不被静态服务公开，不打包到网页，推荐使用 Git 忽略的 `runtime/research/`。文件未加密，仍属敏感资料。去标识不是匿名化。

每次只使用最新的完整授权快照，14 天以上的快照拒绝处理。此期限是产品规则，不保证授权仍然有效。每次训练或使用模型前仍需核对最新授权；撤回后，应停用受影响的数据版本、派生模型及报告，并按管理要求逐项删除相应副本，不能继续拿旧版本训练。当前工具不自动删除旧文件，也不自动完成模型遗忘或远程撤回通知。

## 学什么，不学什么

第一阶段的任务是预测“在给定动作、重量、次数下，实际还能做几次与目标相差多少”，不是直接预测最佳训练重量。标签是 `实际 RIR - 开始时冻结的目标 RIR`。正数表示比预计轻松，负数表示比预计吃力。

仅有“100 kg 做了 5 次”不足以判断接近极限与否。需要记录逐组余力、动作是否合格、是否成功及开始时的目标，不能用主项 PB 替代所有动作能力，也不能把专家用户的高重量直接当作他人的目标。

首版样本筛选：

- 只纳入实际成功、合格的工作组；未完成、放弃、热身、试重不进入回归标签。
- 实际重量/次数必须与冻结目标相同；临时改量、缺少目标、补录或疼痛状态暂不进入该任务。
- 缺少 RIR 不补造；界面“5+”为截断值，不当作精确 5 次训练回归。
- 杠铃总重、哑铃单只重量等保持原计量。器械需要已确认标识，默认器械标识不用于建模；自重、助力、按秒动作暂不支持此任务。
- 过去同动作能力只来自更早日期且同器械的合格记录；不使用同一天未知先后顺序的记录。
- 当前档案 PB、体重、年龄不能倒填成几个月前的状态。0.2.5 起新训练冻结档案和规则版本；旧记录保持未知。疲劳可能来自界面默认值，只作弱特征，不能冒充客观测量。

失败组暂不作为余力回归标签，但必须在未来独立的安全/完成率评估中审计。仅对成功且余力已知的组得到好误差，不代表对所有训练安全或有效。

## 如何进入本地深度学习

建议按以下顺序推进，当前已完成前两项的基础工具：

1. 统一数据口径及授权快照，输出质量报告。
2. 用“预计恰好达到目标余力”和“最近同动作个人偏差”两个基线评估。
3. 先比较正则化线性模型、树模型，再考虑本地 PyTorch 的小型 MLP。表格数据并不天然适合深度学习，不能认为神经网络必然优于简单模型。[Grinsztajn 等，NeurIPS 2022](https://arxiv.org/abs/2207.08815)
4. 初始 MLP 可用数值特征及缺失掩码、动作/计量编码；仅训练集拟合标准化、缺失值填补与词表。不得把 participant、session、实际 RIR、label、split 或测试结果作为输入特征。`baseline` 是比较对象，不是标签替代品。
5. 只预测余力偏差及不确定性，在本地并行计算候选建议，不改变在线计划；不确定、新动作或分布外输入回退现有规则。与规则相比，报告逐用户/逐动作 MAE、过度乐观比例、覆盖率和失败组遗漏率。
6. 对验证集选择超参数，最终测试集只在冻结模型后评估一次。当前工具提供全局日期顺序切分及稳定约 20% 新用户留出；训练组不能随机混入测试组。按用户/会话重采样置信区间，不把同一人的多组当独立受试者。[scikit-learn 交叉验证文档](https://scikit-learn.org/stable/modules/cross_validation.html)
7. 通过专业复核、前瞻性影子运行和版本化发布审批后，才讨论调整少量个体参数。任何模型不得绕过疼痛、恢复、器械单位、未知负荷、PB 测试资格等硬限制；保留原版本回滚。

工具预筛选要求至少 20 人、1,000 个可用组、56 天跨度，并有独立训练/验证/时间测试/新用户测试样本。**这只是人为设置的起步检查，不是证明深度学习可用的统计门槛**。报告即使显示 `offline-experiment-candidate`，也始终是 `canDeploy: false`。样本少时优先完善记录与同动作个人校准，不强行训练深度模型。

## 训练目标和证据边界

余力反馈可帮助调节阻力训练，但既有自我调节研究不等于验证本软件的个人公式或机器学习模型。[自我调节系统综述](https://pubmed.ncbi.nlm.nih.gov/35038063/)

训练日志是观察数据：用户自行选择重量、器械和日期，经验、睡眠及伤病等混杂因素常常缺失。专家用户只是不同人群，不能自动获得更高“真值”权重。即便模型能预测余力，也不能证明该计划导致更快力量提升、更多增肌或更低伤害风险。后续需要独立效果评估和专业审定。

## 接口与未完成项

- 已实现：管理员 `GET /api/admin/research-export` schema 2；完整当前授权名单、稳定去标识用户/训练/组标识、冻结目标、实际结果、模拟数据过滤、导出审计；拒绝调试身份导出。
- 已实现：离线准备命令，拒绝管理备份/旧格式/过期文件、重复 ID 质检、时间和用户隔离、两个基线与空样本报告；新训练冻结计算版本及档案上下文。
- 未实现：模型训练器、学习曲线、置信区间、失败/不适风险模型、因果效果研究、自动化周下载任务、模型发布/回滚服务、授权撤回的自动文件清理。没有任何网络模型调用或付费 API。
- 当前周下载为手动管理员入口，不是定时后台下载。备份与研究导出独立保存，后者不能替代完整运维备份。
