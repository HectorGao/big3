# 举个铁子 v0.2.1 / 20260921.2

## 变更

- 回声表情面板移入文档流，窄屏不再依赖可能被裁切的浮层。完整展示 12 个可选表情，使用系统彩色表情字体和 44 px 触点。按钮明确设置为 `type=button`，仅插入表情，不触发发布。顶部摘要增加足够行高和卡片高度，完整原文仍可在回声详情中阅读。
- 玻璃背景除了原有 backdrop blur，加入随强度变化的光学柔化；纯文字样式不受影响。管理员设置新增同一张器械图片的 0 px 与当前值材质对照。背景始终是装饰层，回声原文、输入与训练内容不随之模糊；减少透明度/增强对比偏好仍优先。
- 网页计划卡片与进行中动作支持单独/全部收起。紧凑摘要保留动作名、器械、重量、组次、单位、图解；进行中摘要包括完成和放弃组数。不同组数值显示区间，不伪造均值；未知重量显示待试重，自重与秒数分开标注。
- 折叠时保留真实输入节点、拖动手柄与冻结目标。展开状态按账号、训练上下文及动作保存在当前页面内存，不上传到训练档案；重排、查看图解和往返页面保留状态，重新加载回到展开。折叠动画服从系统减少动态效果。
- 微信计划页支持单独/全部收起。没有重构原生进行中训练的逐组结构，也没有新增原生拖拽；网页验证不代表原生运行验证。
