# Three Lift Mini Program Implementation Plan

**Goal:** Deliver a native WeChat mini program with muscle selection, daily three-lift programming, editable PBs and local workout records.
**Architecture:** Native WXML/WXSS pages share dependency-free CommonJS data, planning and storage modules. A browser preview exercises the same engine, not a claim of native runtime validation.
**Tech Stack:** WeChat native components, Canvas 2D, JavaScript, Node built-in tests.
**Spec:** User-approved four-page design in this conversation (2026-09-09).

## Constraints
- No bulk deletion; no external data upload or account creation.
- No copied MuscleWiki assets. Original interactive muscle map and generated equipment photography.
- Missing AppID, developer tools, credentials or review approval are release blockers, not reasons to fake successful deployment.
- Training templates are conservative product heuristics for healthy adults, not validated individualized prescriptions.
- Local storage only; export/import with strict validation and error reporting.

## Tasks
- [x] Write and run failing Node assertions for PB validation, cycle selection, fatigue/pain gates, history ordering, logging and persistence.
- [x] Implement `miniprogram/lib/catalog.js`, `planner.js`, `store.js` with round-down plate increments, no unknown-PB weight, and no automatic max attempts.
- [x] Implement today/atlas/history/profile pages, native config, original Canvas anatomy and accessible named muscle alternatives.
- [x] Implement browser preview using shared planner/catalog/map, then verify at mobile and desktop sizes.
- [x] Run native page-controller checks and config integrity checks. Document native-tool and release gaps.

## Acceptance
`npm test` must cover no-PB entry, invalid values/dates, training cycles, same-day/recent overlap, missed-session handling, fatigue/pain, actual set logs, storage failure and backup validation. Manual preview checks must cover selecting a muscle, changing a lift, saving PB, completing sets, history and narrow-screen layout.

## Evidence
- ACSM 2026 overview: https://acsm.org/resistance-training-guidelines-update-2026/ . Broad support for regular resistance training, heavier loads for strength, individualized progression. Exact application thresholds are product defaults, not ACSM claims.
- WeChat release workflow: https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html . Upload, review and publication are distinct steps.
