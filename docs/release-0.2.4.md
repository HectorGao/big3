# 举个铁子 v0.2.4 / 20260922.2

## 变更

- 核对本地四个 demo 账号口令仍有效，未重置测试或管理员密码，未向前端增加口令提示。
- 生产配置要求 HTTPS 来源；默认使用独立生产数据库，并拒绝含 demo 账号的数据库。正式环境禁用网页管理员初始化、demo 调试与 demo 登录令牌。普通注册不能指定管理员角色。
- 新增 `npm run admin:create`：在服务器终端交互创建管理员，密码不回显、不接受命令行参数或非交互管道，没有固定管理员密码；已有管理员不可被覆盖。
- 用户管理增加“下载每周档案备份”及最近生成时间。导出真实用户的独立档案、训练记录和完整用户状态，不导出密码、密码哈希、会话令牌或 demo 账号；导出写入管理员审计日志，不改写任何用户数据。
- 管理备份与自愿授权的研究导出保持独立。备份为未加密 JSON，操作前明确提示私密保存；它不是自动同步、自动定时任务或完整服务器恢复包。
- 静态构建检查增加本地 demo 口令泄漏检查，备份文件名加入 Git 忽略。

部署说明及每周步骤见 [正式账号与备份](production-accounts-backup.md)。

- 桌面与手机浏览器实际下载 JSON 并解析，确认数据内容、账号隔离、凭证排除、用户档案不变、每周状态更新；确认普通账号和调试身份没有备份权限。
