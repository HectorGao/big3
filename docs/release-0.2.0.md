## 接口

- `GET /api/health`：品牌、软件版本、构建号、本地实例标识（非凭证）。
- `GET /api/echo-settings`：公开展示配置，返回 `revision/config/updatedAt`。
- `GET /api/board`：公开未隐藏留言和相同设置快照。
- `GET /api/admin/echo-settings`：管理员读取设置。
- `PUT /api/admin/echo-settings`：管理员提交 `{revision, config}`，配置必须包含共享模块定义的全部字段。不接受任意 CSS、HTML 或脚本，颜色只接受六位十六进制值。
- 未登录 401，非管理员 403，来源不符 403，字段无效 400，并发版本过时 409；配置与审计同一事务提交，失败回滚。管理员调试 demo 时按真实管理员身份授权和审计。

`site_settings` 表与用户档案独立，配置变更不更新用户同步 revision。默认值和校验在 `miniprogram/lib/echo-settings.js`；仅新表插入默认行，重启不重置已保存设置。若允许个人偏好，已有本机顶部风格优先；关闭该选项则全站统一。个人暂停与操作系统辅助设置始终优先。

## 本地服务

在项目目录运行 `npm run start:local`。命令创建分离的 Node 子进程，写入 `runtime/local-server.json`，日志在 `runtime/local-server.log`。状态/停止命令核对健康接口实例标识后才操作自己的 PID，不结束占用端口的其他程序。未安装系统自启动项，也没有自动监控或重启机制。更新后 `npm run restart:local`，重启电脑后 `npm run start:local`。

仍仅监听 `127.0.0.1`；不能把该地址作为手机远程访问或公网部署。已有域名/线上版本本轮未修改。SQLite 原库升级前通过 backup API 保存在 `runtime/big3-before-echo-v020-*.sqlite`，不纳入 Git 或静态包。
