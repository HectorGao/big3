# 举个铁子 v0.2.2 / 20260921.3

## 变更

- 肌群涉及组数在共享汇总入口转换为整数后相加，修复手动编辑组数时 `3 + 2` 拼成 `032` 的问题。零组不增加计数，缺失、负数、小数或无效值不补造工作组；真实合计可超过五组，不按热度颜色等级截断。
- 实际完成组逐组计数，不混入计划组；进行中训练与历史记录统一排除热身和试重组。汇总不修改档案、计划输入或历史。
- 删除后来添加的中分发型绘制层，正面和背面恢复原始头部轮廓。保留肌群点击区域、正背面解剖差异及热度颜色。
- 酸痛图的正背面切换按钮明确为非提交按钮，切换视图不会保存反馈或重新规划。

## 验证

- 新增三项共享回归测试，修改前复现 `032` 拼接等错误，修改后通过；`npm test` 共 170 项通过。
- `npm run test:soreness-browser`：1280、768、390、360 px，实际操作组数输入、打开酸痛界面，验证 `5 组涉及`、零组及无前导零的整数格式；切换正背面、点击肌群后不提交反馈、不修改原数据。
- 同脚本检查正背面与热度颜色的画布像素，输出头部、全身及酸痛界面截图；人工查看正背面头部、桌面人体图和手机酸痛界面，无横向溢出。
- 网页构建及产物检查通过，产物不包含用户数据。浏览器使用独立临时数据库与测试档案，不修改真实账号和训练记录。
