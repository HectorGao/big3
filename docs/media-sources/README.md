# 举个铁子 · 教学素材说明

[文档导航](../README.md) · [小程序分包](../../miniprogram/README.md)

当前动作库包含 **52 个动作、153 个可查看阶段**。图片采用浅灰人体、粉色重点肌群和清晰器械的教学风格，动态动作与静态动作按各自流程设计，不使用同一人物侧面模板冒充所有动作。

## 来源与结构

- 图片由内置图像生成工具原创生成，MuscleWiki 仅作为动作分类和示范参考，不复制其视频、图片或源码。
- 本目录每个动作的 JSON 记录来源、初步检查状态及意见；`original` 等路径是生成时的本机来源线索，不是公共下载链接。新克隆不需要访问这些私有原图路径即可使用优化素材。
- [media-manifest.js](../../miniprogram/lib/media-manifest.js) 是网页与微信共用的图片和阶段清单；已优化图片位于五个 `miniprogram/media-*/assets/` 分包。
- 人体肌群点击图由 [anatomy.js](../../miniprogram/lib/anatomy.js) 单独绘制，不是这些动作图片的热区映射。

## 审核含义

`status: reviewed` 表示助手已做视觉筛查，范围以 `reviewScope` 和 `reviewNotes` 为准。**不表示专业教练、生物力学专家或医疗人员认证。** 文件能加载、画布非空及阶段能切换也不能证明姿势完全正确。

修改素材应核对关节、杠铃方向、握点、支撑点、动作过程和中文说明，保留来源及复核记录。不能只修改状态字段来满足完整性测试。

## 构建检查

在仓库根目录执行 `npm run check:release-media`，检查覆盖、文件和分包源码预算；`npm run test:web` 可检查网页阶段切换和放大。

正常运行使用已提交素材，不需重新生成。只有具备私密原图来源时才运行 `npm run build:media`；原图与工作产物留在 `art-originals/` 等发布排除区，不公开上传。微信最终编译包大小和真机图像显示仍需另外验收。
