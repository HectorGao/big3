# 收藏、补录与训练回声

## 本轮功能

- 注册主确认仅说明档案与记录保存到服务器。可展开的数据说明仍披露管理员权限、公开留言和访客导入范围。
- 顶部提供“训练回声”和“写点想法”。阅读区显示最新 100 条内容，顶部精选最新 8 条循环。登录者可发布训练日常、改进建议、一起讨论三类内容；管理员可隐藏、恢复显示，操作进入审计日志。作者及管理员原有的逐条删除功能保留。
- 当前支持“轻盈横滑、斜向弹幕、双列上浮、静态精选”四种可选风格，这是用户后续要求恢复风格选择后的版本。顶部约 14 px/s、背景约 8 px/s、纵向不超过 10 px/s；内容不变时刷新不重启动画。遵循暂停、减少动态和减少透明度设置。详见 [卡片排序与回声风格](motion-echo.md)。
- 替换窗口固定展示原动作，按原动作全部涉及肌群标亮，器械筛选不会把原动作移走。
- 计划动作支持三横线拖拽、上移/下移、恢复默认顺序、移除动作。数字输入支持增减按钮、计划及补录字段的滑动调节，重量步长优先采用动作档位，其次采用档案最小增量；不改变每只哑铃、杠铃总重等原有单位。
- 收藏保存动作顺序、组次、重量与计量来源，按主项和训练日筛选，卡片可横向滑动。可沿用同类型历史。重新使用时经过当前处方与恢复限制复核；收藏不证明当前能力。
- 补录导入默认建议、收藏或近期实际训练。补录草稿独立存储，没有组间计时；逐组确认实际完成值，未确认组不计训练量。补录失败保留草稿，保存不清除正在进行的训练。只有实际成功、动作合格并符合既有规则的组才更新成绩。
- 待定重量填入后带入同动作其余待定组。实际保存后的同动作、同设备记录参与后续处方；次数改变或缺少可靠余力时仍可能要求重新试重，不虚构能力。
- 酸痛对话框展示计划/实际肌群涉及组数热图，并明确标注来源。深色仅表示被更多组涉及，不是恢复率，也不是肌肉激活的测量结果。
- 概览新增近 28 天训练天数与上期比较、实际成功组数、余力覆盖、收藏数量与三项分布。人体正背面增加原创中分发型轮廓，不是人物代言或身份认证。

## 数据与调试账号

存储版本升为 v4。首次写入前备份旧版本原始内容；保留旧记录、旧单位和实时训练草稿。新增 `favorites`、`retroDraft`。账号同步仍使用版本冲突检测，不自动合并或覆盖别的设备。

`npm run seed:demo` 只向本机数据库添加模拟账号，不修改已有同名模拟账号；遇到同名真实账号整批回滚。不会初始化或替换管理员。运行前后无需清理浏览器存储。

调试账号：`demo`、`demo_beginner`、`demo_strength`、`demo_muscle`。

管理员可在“账号 → 用户管理 → 进入调试”免输 demo 密码，顶部持续标明当前身份，并可“返回管理员”。调试令牌绑定当前管理员登录会话、存放在本标签页的 sessionStorage，2 小时有效，不替换登录 Cookie；普通新标签页仍是管理员。仅模拟账号允许切入，不冒用真实成员身份。进入、保存、发言、退出写入审计日志；调试期间仍可管理留言及查看用户列表，不修改 demo 的研究授权。

切换前先同步当前档案；冲突与离线失败阻止切换。调试到期时允许返回管理员，未上传修改留在原 demo 的独立本机缓存，重新进入后继续同步；不把它导入管理员档案。刷新页面保留有效调试身份。密码最低长度已在前后端统一为 8 位，最大 128 位，保留 scrypt 和登录限流。

新创建的调试账号使用随机密码，保存到生成脚本返回的本机私密凭证文件，不在源码或公开文档中提供。既有本地账号密码不变。这些不是生产账号或管理员密码。每个账号有 39 次、覆盖约三个月的模拟训练，另有 100 条带模拟标识的留言。账号、记录均标记为合成数据。重复运行不覆盖修改过的数据。管理员的研究导出排除模拟账号，以及带合成标识的导入数据。

不得将含调试账号的服务器直接开放到互联网；正式部署使用独立数据库并关闭调试入口。无需也不会为了测试清空真实用户数据。

## 科学边界

- 研究支持原则：训练开始时优先安排的动作通常获得更大的专项力量收益；尚不能据此宣称某一顺序对每个人的增肌都最优。[Nunes 等系统综述及荟萃分析](https://pubmed.ncbi.nlm.nih.gov/32077380/)。允许调整顺序，主项后置时提醒重新热身与核对余力，不凭顺序任意加重。
- 个体调节依据：实际完成量、同动作负荷与主观余力可以辅助调整训练；自我调节不等于保证优于一切标准化安排。[负荷与训练量自我调节综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC8762534/)。缺少反馈继续显示不确定性。
- 产品规则：收藏复用不超过当前建议重量，疲劳较高时不突破原减量组数；常规日每日工作组上限沿用既有 14/24 组设置。这些数值是可校准产品默认值，不是文献验证的个人安全阈值。
- 历史补录是对已经发生事实的记录，不是对疼痛或疲劳下训练的许可。模拟数据不修正全局算法，也不作为疗效或进步证据。
