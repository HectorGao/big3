# 举个铁子

围绕**深蹲、卧推、硬拉**的力量训练辅助工具，帮助你安排训练、学习动作、记录表现，并根据实际完成情况调整后续计划。

目标不是让每次训练都冲击极限，而是让力量提升或增肌训练更有依据、更容易执行和持续追踪。网页适配电脑与手机，微信小程序共用核心训练逻辑；原生 App 尚未发布。

[打开网页版](https://hectorgao.github.io/big3/)（GitHub Pages）。此入口的训练记录仅保存在当前浏览器，暂不支持账号登录和跨设备同步；请定期在“我的档案”导出备份。

## 能帮你做什么

- **安排训练**：结合训练目标、经验、三大项成绩和疲劳反馈，给出动作、重量、组次、休息与目标余力，滚动规划未来两周。
- **选择动作**：点击正背面肌群图，查看动作图解；按杠铃、哑铃、器械、绳索或自重筛选，替换或增加适合自己的动作。
- **记录进步**：保留逐组实际表现，查看训练量、三大项成绩和估算单次能力（e1RM）的变化，明确区分实测与估算。
- **灵活执行**：支持调整动作顺序、收藏方案、临时换项、跳过恢复日和事后补录。未完成的计划不会计入实际训练量。

## 如何使用

1. **建立档案**：在“我的档案”填写年龄、体重、训练经验、主要目标、可训练日及最小加重档位。录入三大项实际完成的重量、次数和日期。
2. **选择当天训练**：进入“今日训练”，选择日期和深蹲、卧推或硬拉，按需选择容量日、强度日、技术日或恢复日；填写疲劳、酸痛与疼痛反馈，查看计划及调整理由。
3. **确认动作和重量**：查看图解，按可用器械替换、增加或排序动作。无可靠同动作记录时显示“待试重”，先确认可控负荷，不用其他动作的 PB 硬套重量。
4. **记录实际完成**：开始后逐组填写重量、次数和“还能做几次”（RIR）。例如 RIR 2 表示预计还能规范完成约 2 次；做不到的组可放弃，不必为完成表格勉强训练。
5. **保存并回顾**：结束保存后，系统依据实际训练和反馈重新安排未来两周。在“概览”查看趋势，在“训练记录”回顾明细；常用组合可收藏，漏记的训练可按实际日期补录。

PB 测试需主动开启并满足资格、恢复及保护条件，不是普通强度日的默认任务。账号同步和“训练回声”是否可用以所访问站点为准；本机记录请定期导出备份。

## 训练规划的依据

规划参考抗阻训练指南和相关研究，将**目标导向的负荷与训练量、渐进训练、实际表现反馈及动作特异性**用于计划设计。具体组次、疲劳阈值和调整幅度是可校准的产品规则，不是文献对每位用户的直接处方。

### 主要参考文献

1. **ACSM（2009）**：[健康成人抗阻训练的进阶模型](https://pubmed.ncbi.nlm.nih.gov/19204579/)。*Medicine & Science in Sports & Exercise*。参考按目标与经验安排负荷、组次、休息及渐进训练的原则。
2. **ACSM（2026）**：[抗阻训练指南更新官方解读](https://acsm.org/resistance-training-guidelines-update-2026/)。强调持续参与、个体可执行性，以及力量与增肌目标的不同侧重；一般健康成人指南不能直接替代竞技训练者的专项安排。
3. **Hickmott 等（2022）**：[负荷与训练量自我调节对力量和增肌的影响：系统综述与 Meta 分析](https://pubmed.ncbi.nlm.nih.gov/35038063/)。*Sports Medicine - Open*。为反馈调整提供参考；有训练经验者的研究中，自我调节负荷未显示显著优于标准化负荷的力量收益。
4. **Zourdos 等（2016）**：[以剩余次数衡量抗阻训练用力程度的 RPE 量表](https://pubmed.ncbi.nlm.nih.gov/26049792/)。*Journal of Strength and Conditioning Research*。参考 RPE/RIR 记录方法；研究以年轻深蹲训练者为对象，余力判断并非适用于所有人的精确测量。
5. **Haugen 等（2023）**：[自由重量与器械训练对力量、增肌及跳跃表现的影响：系统综述与 Meta 分析](https://pubmed.ncbi.nlm.nih.gov/37582807/)。*BMC Sports Science, Medicine and Rehabilitation*。成人研究未检出两种方式的增肌差异，力量适应具有训练方式特异性；器械可以参与训练，但成绩不直接换算为杠铃 PB。

本工具面向一般健康成人的训练辅助，不替代教练现场指导或医疗评估。e1RM 和恢复提示均有不确定性；引用研究不代表本软件已经过效果验证，也不承诺“最优计划”。疼痛或明显不适时不应继续执行负重建议。
