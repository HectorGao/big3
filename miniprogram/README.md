# 举个铁子 · 微信小程序

[项目首页](../README.md) · [文档导航](../docs/README.md)

原生微信小程序源码。概览、今日训练、肌肉图谱、训练记录、我的档案共五个导航入口。核心处方、动作定义和数据校验与网页共用；网页账号服务与部分新版交互尚未接入微信，不能宣称所有功能完全一致。

## 导入与运行边界

1. 在微信开发者工具中导入**仓库根目录**，不是单独导入 `miniprogram/`。
2. 根目录 [project.config.json](../project.config.json) 已配置 `miniprogramRoot`。
3. 当前 AppID 是 `touristappid` 占位；正式预览、上传和审核需要自己的真实 AppID、相应权限及平台配置。
4. 小程序代码没有 npm 运行时依赖；网页使用的 Lucide 不需要在微信端构建。
5. 检查个人档案、真实日期保存、跨日草稿、动作详情分包、数据导入导出和手机触控。

**当前没有完成微信开发者工具编译或真机验收，没有提交审核。** Node 模拟页面控制器及网页测试不能替代这些环节；正式发布的资质、隐私和平台要求需另行确认。

## 目录与共用逻辑

| 目录 / 文件 | 用途 |
| --- | --- |
| `pages/` | 五个业务页面 |
| `lib/catalog.js` | 52 个动作、肌群、器械与计量方式 |
| `lib/coach.js`、`lib/planner.js` | 滚动计划、恢复限制、逐组处方与训练会话 |
| `lib/science.js` | 估算与科学依据支持逻辑 |
| `lib/store.js`、`lib/routines.js` | 数据验证、迁移、实际记录、收藏 |
| `lib/anatomy.js` | 正背面可点击人体肌群 |
| `lib/media-manifest.js` | 统一图片与阶段清单 |
| `lib/release.js` | 应用名称、版本、构建号 |
| `media-squat/`、`media-hinge/`、`media-push/`、`media-pull/`、`media-core/` | 动作详情与图片分包 |

主包不能直接引用其他分包的图片；进入对应详情页后使用分包资源。网页复用这份素材清单。

## 检查

在仓库根目录运行：

```sh
npm test
npm run check:release-media
```

测试包含共享计算与微信页面控制器模拟。包体脚本使用每包 1.8 MiB、总计 18 MiB 的保守源码预算，并检查素材覆盖；这不是微信开发者工具最终编译大小或审核结果。

小程序实际训练保存在微信本地存储，不在 Git，不会自动同步网页账号。更改存储结构时必须保留迁移备份，不能为换名或更新界面改存储键、清空历史或抹掉草稿。
