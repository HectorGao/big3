# 举个铁子 · 离线研究准备

[项目首页](../README.md) · [完整研究流程与局限](../docs/local-model-preparation.md)

本模块目前提供**授权数据质检、样本划分与非学习基线**，没有深度学习训练器，也没有上线模型或证明改善训练效果。

## 输入与执行

管理员在账号窗口选择“导出授权研究数据”，使用当前 schema 2 快照。仅纳入明确授权的真实用户；模拟账号被排除。管理周备份是另一种文件，不能作为研究输入。

在仓库根目录运行，输入替换为实际私密文件路径，输出必须是尚不存在的新目录：

```sh
npm run research:prepare -- /private/path/consented-snapshot.json runtime/research/new-run
```

仅处理最新完整快照；超过 14 天的输入被拒绝，不合并多周快照，不覆盖既有结果。14 天是产品规则，不是对授权有效性的保证，使用前仍需确认最新授权。

| 输出 | 内容 |
| --- | --- |
| `manifest.json` | 快照来源、校验值、样本任务、特征清单 |
| `dataset.json` | 质检后的逐组数据和评估划分 |
| `report.json` | 人数、样本量、排除原因、两个基线误差与使用限制 |

输出目录权限 `0700`，文件权限 `0600`，但内容没有加密。去标识不等于匿名；输入输出和后续模型必须留在私密、Git 忽略的位置。

## 当前评估目标

标签为“实际剩余次数 RIR 减去开始训练时冻结的目标 RIR”，不是最佳重量。只纳入符合计量、器械、动作质量和完成条件的工作组；缺失或截断反馈不补造。当前档案不能倒填历史时点。

使用按时间和按用户隔离的评估集，对比零偏差与近期同动作个人偏差基线，避免把同一个人的相邻组随机分到训练和测试中。具体筛选、门槛及遗漏风险见完整研究文档。

## 后续边界

程序始终返回 `canDeploy: false`。更多用户数据不自动等于更可靠的模型；专家的高重量不能直接成为其他人的目标。后续仍需授权治理、模型比较、独立效果评估、专业审定和发布审批，且不得绕过疼痛、恢复、单位及未知负荷限制。

撤回授权后，旧快照、派生结果和模型需按要求处理；本工具不会自动清理文件或完成模型遗忘。不要将实际用户资料上传到 GitHub Issue 或用它构造公开测试样本。
